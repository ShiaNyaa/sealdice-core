# Inspira UI

来源：https://github.com/unovue/inspira-ui （MIT）
同步方式：按组件复制源码，不做 npm 依赖。当前收录：

- `NumberTicker.vue` — 数字过渡（首页指标）
- `BlurReveal.vue` — 模糊入场（关于页主视觉）
- `BentoGrid.vue` / `BentoGridItem.vue` / `BentoGridCard.vue` — 网格骨架
- `ShimmerButton.vue` — 微光按钮

组件内的 `cn()` 来自 `src/lib/cn.ts`，替代上游的 `@inspira-ui/plugins`。
